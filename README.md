# دكانتنا 🧺

تطبيق طلبات لدكانة الحارة: الزبون بيختار أغراضه، وبيبعت الطلب، وبيتابع حالته لايف.

- `public/` — التطبيق نفسه (بينشر على Netlify).
- `public/config.js` — إعدادات Firebase.
- `firestore.rules` — قواعد حماية قاعدة البيانات (بتنلصق بـ Firebase ← Firestore ← Rules).

الأسعار والمنتجات والإعدادات بتتعدّل من داخل التطبيق: حسابي ← 🔑 دخول صاحب الدكانة.
